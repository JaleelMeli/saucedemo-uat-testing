
# SauceDemo UAT Testing

User acceptance testing for the SauceDemo e-commerce site (https://www.saucedemo.com), written from the shopper's point of view.

## What's in this repo
- `UAT-SauceDemo-Portfolio.pdf`: two user stories, acceptance criteria, test cases and sign-offs

## Summary
| Story | Feature | Test cases | Result |
|---|---|---|---|
| US-01 | Login | 4 (TC-01 to TC-04) | 4 passed, Accepted |
| US-02 | Checkout | 4 (TC-05 to TC-08) | 4 passed, Accepted |

## Approach
- User stories written as "As a shopper, I want..."
- Acceptance criteria in Given/When/Then format
- Each test case linked to its story in Jira, with environment, test data, steps, expected and actual results
- A UAT sign-off for each story

Environment: Safari on macOS
